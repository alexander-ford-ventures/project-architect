## Notes on intentional edge cases

These behaviors are by design and should NOT be reported as issues:

- **CLI / library / plugin projects skipping auth / database / frontend questions.** Routing rules in `references/questioning-flow.md` and `references/document-catalog.md` intentionally bypass these for project types that don't need them.
- **`recommended_plugins[].missing: true` entries in `.claude/recommended-plugins.md` for plugins you chose NOT to install at Preflight.** That's the new Phase -1 soft-dep contract.
- **`docs/_architect_state.json` deleted at end of Phase 6.** Cleanup is intentional. The state is meant to live only for the duration of the bootstrap.
- **No PR opened in local-only test runs.** PR creation is gated on `state.git.has_remote == true` AND working on a `bootstrap/architect-*` branch. Greenfield + local-only skips both gates.
